# Plan Codex Review

Claude Code에서 plan mode가 종료되면 **자동으로** 플랜 파일을 OpenAI Codex CLI로 전송하여 다각도 리뷰를 수행하고, 그 결과를 플랜 파일에 병합하여 구현 계획을 고도화합니다.

## 주요 기능

이 스킬은 다음과 같은 방식으로 플랜 파일을 리뷰하고 개선합니다:

- **plan mode 종료 후 자동 실행** — 별도 요청 없이 즉시 Codex 리뷰 시작
- `~/.claude/plans/`에서 최신 플랜 파일 자동 감지
- 7가지 관점(기술적 타당성, 보안, 성능, 테스트, 대안, 의존성, 에러 처리)에서 종합 리뷰
- Codex CLI를 read-only 샌드박스 모드로 안전하게 실행
- 리뷰 결과를 원본 플랜 파일에 자동 병합
- 심각도별(Critical/High/Medium/Low/Info) 분류된 액션 아이템 생성
- Codex CLI 미설치 시 경고만 출력하고 구현 진행 (블로킹하지 않음)

## 자동 실행

이 스킬은 **plan mode가 종료되고 사용자가 플랜을 승인하면 자동으로 실행**됩니다.

### 자동 실행 흐름
1. `Shift+Tab`으로 plan mode 진입
2. Claude Code가 구현 계획 작성
3. 사용자가 플랜 승인
4. **→ 자동으로 Codex CLI 리뷰 시작** (별도 요청 불필요)
5. 리뷰 결과를 플랜 파일에 병합
6. 사용자에게 다음 단계 선택 요청 (리뷰 반영 / 바로 구현 / 재리뷰)

### 건너뛰기
다음과 같이 요청하면 자동 리뷰를 건너뜁니다:
- "리뷰 없이 진행해줘"
- "Codex 리뷰 건너뛰기"
- 단순한 변경(단일 파일, 10줄 미만 변경)인 경우

## 수동 사용

자동 실행 외에도 직접 요청할 수 있습니다:

- 구현 계획을 Codex로 리뷰받고 싶을 때
- 플랜의 보안 취약점이나 성능 이슈를 사전에 발견하고 싶을 때
- 다른 AI 관점에서 구현 계획을 검증하고 싶을 때
- 플랜의 기술적 타당성을 다각도로 분석하고 싶을 때
- 구현 전에 플랜을 고도화하고 싶을 때

## 사전 요구사항

```bash

```


## 리뷰 관점

7가지 관점에서 플랜을 분석합니다:

### 1. 기술적 타당성 (Technical Feasibility)
구현 단계의 완전성, 순서 정확성, 기술 선택의 적절성, 엣지 케이스 커버리지를 검토합니다.

### 2. 보안 (Security)
OWASP Top 10 취약점, 인증/인가, 데이터 검증, 인젝션 위험, 시크릿 관리를 점검합니다.

### 3. 성능 (Performance)
N+1 쿼리, 캐싱 전략, 비동기 처리, 데이터베이스 인덱스, 페이지네이션을 분석합니다.

### 4. 테스트 전략 (Test Strategy)
단위/통합/E2E 테스트 커버리지, 엣지 케이스 테스트, 모킹 전략을 평가합니다.

### 5. 대안 (Alternative Approaches)
더 단순한 해법, 적합한 디자인 패턴, 기존 라이브러리 활용 가능성을 검토합니다.

### 6. 의존성 (Dependencies)
버전 호환성, 보안 취약점, 라이선스 호환성, 번들 사이즈 영향을 확인합니다.

### 7. 에러 처리 (Error Handling)
실패 모드 식별, 복구 전략, 로깅/모니터링, 타임아웃/재시도 전략을 평가합니다.

## 동작 방식

1. **[자동 트리거]** plan mode 종료 → 사용자 승인 → 리뷰 자동 시작 안내
2. **플랜 파일 감지**: `~/.claude/plans/`에서 방금 생성된 플랜 파일 자동 선택
3. **사전 검증**: Codex CLI 설치 및 인증 상태 확인 (실패 시 경고 후 건너뜀)
4. **플랜 읽기**: 플랜 파일 내용 읽기
5. **프롬프트 작성**: 마스터 리뷰 템플릿에 플랜 내용을 삽입
6. **Codex 실행**: `codex exec -s read-only --full-auto` 명령으로 실행
7. **출력 파싱**: Codex 출력에서 섹션별 결과 추출
8. **결과 병합**: 원본 플랜 파일 끝에 `## Codex Review` 섹션 추가
9. **요약 제시**: 사용자에게 주요 발견사항과 액션 아이템 요약
10. **다음 단계 선택**: 리뷰 반영 / 바로 구현 / 재리뷰 중 선택

## 에러 처리

| 에러 | 대응 |
|------|------|
| Codex CLI 미설치 | 설치 명령어 안내 후 중단 |
| 인증 미설정 | 인증 방법 안내 후 중단 |
| 플랜 파일 없음 | 경로 입력 요청 또는 플랜 생성 안내 |
| 플랜 파일 비어있음 | 경고 후 중단 |
| 실행 타임아웃 (5분) | 가벼운 모델로 재시도 안내 |
| Codex 출력 없음 | 다른 모델로 재시도 안내 |
| 출력 형식 비정상 | raw 출력 그대로 append, 형식 경고 |
| 파일 쓰기 실패 | 콘솔에 리뷰 결과 출력 (손실 방지) |

## 모델 선택 가이드

| 기본값 | 보통 | 깊음 | 보통 | 종합 리뷰 |

## 베스트 프랙티스

- **자동 리뷰 활용**: plan mode 종료 후 자동으로 실행되므로 별도 요청이 필요 없습니다
- **반복 리뷰**: Critical 이슈 수정 후 재실행하여 개선을 확인하세요
- **모델 활용**: 빠른 검토는 `o4-mini`, 심층 리뷰는 기본 모델을 사용하세요
- **결과 보존**: 리뷰 결과가 플랜에 병합되므로 이력이 자동 관리됩니다
- **우선순위 준수**: Critical → High → Medium 순서로 발견사항을 처리하세요
